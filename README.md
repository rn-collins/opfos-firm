# One-Person-Firm OS — Practice Architecture Workbench

Map how your independent practice works, find hidden operational drag, and generate a practical operating architecture, weekly review, AI role cards, and implementation pack.

**Live:** https://opfos-firm.vercel.app

## Repository contents

`index.html`, `photo-rn.jpg`, `privacy.html`, `robots.txt`, `sitemap.xml`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
